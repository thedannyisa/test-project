# Офис Cursor

Маленькое приложение для Мака: облачные агенты Cursor сидят в одной комнате.

- Агент работает — сотрудник печатает.
- Задача закончилась — сотрудник отошёл от стола.
- Агент в архиве — стол пустой.

## Как открыть

Дважды щёлкни `Cursor Office.app` в этой папке.

Нужен Python 3. Если Мак скажет, что его нет, установи его с [python.org](https://www.python.org/downloads/macos/) и открой приложение снова.

Можно и из терминала:

```bash
python3 office/server.py
```

Страница откроется на `http://127.0.0.1:8765`.

## Ключ

В окне офиса вставь ключ из Cursor Dashboard → API Keys. Он сохранится только на этом компьютере, в `~/.config/cursor-office/api-key`. В репозиторий и в чат он не попадает.

Пока ключа нет, офис показывает пример сотрудников. Это не твои агенты.
